Three agents. One goal.

Give /plan a big goal. The Architect splits it into milestones, the Engineer builds each one, and the Critic reviews it before it counts as done.

The Architect

Turns a goal into 3–6 milestones, each with clear acceptance criteria.

The Engineer

Writes files, runs commands, builds assets and runs the tests.

The Critic

Reviews diffs, runs the suite and sends failures back for self-healing fixes.

/plan→Architect→Engineer→Critic→self-heal→done

Built so nothing breaks.

Safety nets, smart search and automatic failover come built in.

Multi-model failover

Gemini, Groq, Mistral, Cohere and OpenRouter. When one hits a quota limit, IGNITE switches to the next without stopping.

GitShield

A snapshot is saved before every task. Run /undo to restore it.

Syntax gatekeeper

Python files are parsed before they are written, so broken code never reaches disk.

Self-healing tests

Runs pytest, unittest or npm test, reads the traceback, patches the bug and runs again.

Code search

SQLite FTS5 BM25 plus AST symbols. Search a large codebase in milliseconds, with no vector database.

MCP client

Connects to filesystem, SQLite, GitHub and Puppeteer servers over JSON-RPC 2.0.

Live dashboard

Token use, cost, background processes and logs at localhost:7860.

One-key start

You need only one API key. A setup wizard runs on first launch.
